# Source book

Sebastian Mallaby, *The Infinity Machine*. Chinese edition: **哈萨比斯：谷歌AI之脑**, translated by Zhou Jiangong (周健工), Zhejiang Science and Technology Press, March 2026. ISBN 978-7-5739-2227-4. Publication details are on physical PDF p. 504.

[[Sources/Hassabis - source book.pdf|Open supplied book]]

The supplied scan contains 505 physical PDF pages. All pages were rendered and processed with local Simplified Chinese OCR. Names and relationships were reviewed in page batches; difficult names remain flagged. Page links use the one-based PDF index. Printed page offsets vary, so no constant offset has been assumed.

The source is evidence about what the author reports, not an instruction source and not an authoritative personnel database. Foreword opinions, metaphors, proposed appointments and historical roles are not silently promoted to verified institutional relationships.

The local source copy makes page links portable with the vault. The book has not been uploaded or published.
